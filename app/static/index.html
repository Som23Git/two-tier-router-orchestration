What happens when you press Send

This page calls the finance-router workflow in Kibana. Every step below is a step in that workflow.

1. Laya decidesAn open-source, non-generative model answers three questions: intent, category and time period, each with probabilities. No text is generated.
2. Confidence checkIf Laya's probability for every answer the message needs is above the threshold, its labels are used as they are.
3. LLM only if neededOtherwise Claude Haiku 5.5 classifies the message. Saving an expense also asks it for the merchant name, which Laya cannot copy.
4. ActIndex: the expense is saved to Elasticsearch. Search: a templated ES|QL query computes the total; no model writes the query.
5. LogEvery decision goes to the router-log index, so the routing itself can be analyzed.

Open any reply's "Open in Kibana" link to see the execution step by step.
